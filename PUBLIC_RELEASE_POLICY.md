# Public release policy

This repository is intentionally **public**, but it is **not** a public mirror of the authors' source archive.

## Never upload here

The following are excluded unless the original study team explicitly approves public release:

- original spreadsheets supplied by the study team;
- the controlled archived source workbook;
- original field sheets, source documents, thesis/source files, correspondence, or author transfer packages;
- row-level source reconstructions or prediction files that could expose the controlled source dataset;
- private review/audit packages.

## Allowed public material

The repository may contain:

- analysis code that does not embed private source values;
- method documentation and claim boundaries;
- aggregate publication-safe tables and figures;
- manuscript build files when the author team approves public posting;
- reproducibility instructions, environment files, and verification manifests;
- public citations and bibliographic metadata.

## Data access statement

Absence of the source workbook from this repository does not mean the data are unavailable to the author team. It means the source archive is controlled and its public release requires an explicit author decision.
