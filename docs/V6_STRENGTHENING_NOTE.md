# V6 strengthening note

V6 preserves the underlying Jordan measurements and fixed-model pipeline while strengthening how the decision claim is tested.

## What changed

1. A separately written blocked-OLS implementation reproduced 54 matched primary model/metal metric combinations to machine precision (maximum absolute difference 3.22e-15 across R2, block-MAE, and Spearman).
2. The primary Mn result is now explicitly stress-tested against blocking and high-set definitions. The exact one-sample C-frequency versus two-fraction ordering is not invariant.
3. Recorded distance and side are shown as a simple context benchmark so that incremental magnetic value is not inferred against an unrealistically weak baseline.
4. The open coastal-sediment data of Ravisankar et al. (Data in Brief, 2018; DOI 10.1016/j.dib.2017.11.056) are used only for a frequency-only portability stress test. They lack matched fine/coarse magnetic fractions and therefore do not externally validate the central Jordan comparison.

## Scientific interpretation

The strengthened conclusion is not that one magnetic configuration is generally superior. The transferable finding is that the preferred additional measurement depends on the declared endpoint, evaluation definition, and available baseline information.

## Public-data boundary

No original study-team Excel, Word, raw/source workbook, row-level prediction output, or private transfer package is included in this public repository.
